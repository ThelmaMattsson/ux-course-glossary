# What is this repo?
An interactive glossary app för learning common frontend concepts, built with React and Tailwind CSS.

# Features
* Search glossary terms
* Filter by course/category
* Interactive flip cards
* Responsive design

# Tech stack
* React
* TypeScript
* Tailwind CSS
* Vite

# Getting started
Clone the repository

Install dependencies:
  npm install

Run the development server:
  npm run dev
